# get-rust

- run `rustc main.rs`
- run the executable file: `./main`

---

### Cargo

- Setup the new repo: `cargo new example`
- Build with: `cargo build`
  - Check the target folder to get the executable file, `target/debug/example`
- Run with: `cargo run`
- Check for the errors with: `cargo check`
- Format the code with: `rustfmt main.rs`

---

- By default all variables are immutable
  - just use the `let mut x = 1;` to make the varibale mutable
